# Proyecto-intermodular-Montaje-y-mantenimiento

Este proyecto detalla el diseño, configuración, montaje y plan de mantenimiento de la infraestructura informática para una asesoría fiscal y gestoría empresarial[cite: 1, 3]. [cite_start]El objetivo principal es proporcionar un entorno de trabajo estable, rápido y eficiente para tareas administrativas y de gestión tributaria[cite: 8, 9].

> **Nota:** Todos los entregables detallados, especificaciones técnicas y planes de mantenimiento se encuentran incluidos dentro del documento del proyecto.

---

##  Análisis de Necesidades
[cite_start]La actividad diaria se centra en la gestión de nóminas, impuestos, contabilidad y comunicación con la Agencia Tributaria[cite: 8]. [cite_start]Se han priorizado equipos con arranque rápido y capacidad multitarea frente a la potencia gráfica[cite: 9].

* [cite_start]**Puestos de trabajo:** 4 equipos de sobremesa estándar[cite: 10].
* [cite_start]**Puesto de dirección:** 1 equipo de alto rendimiento para manejo de ficheros pesados y acceso remoto[cite: 10].
* [cite_start]**Decisión técnica:** Se han descartado portátiles para los puestos fijos por su mayor coste y menor durabilidad en entornos de oficina[cite: 17].

##  Guía de Montaje
El proceso sigue estándares de seguridad y eficiencia técnica:
1.  [cite_start]**Prevención ESD:** Uso de pulsera antiestática para evitar descargas que dañen los componentes a largo plazo[cite: 67, 68].
2.  [cite_start]**Instalación CPU:** Montaje sobre socket LGA1700 alineando el triángulo de referencia sin forzar la palanca[cite: 69, 71].
3.  [cite_start]**Gestión Térmica:** Uso de pasta térmica (tamaño guisante) para asegurar la conducción de calor[cite: 77, 78].
4.  [cite_start]**Gestión de Cables:** Organización interna mediante bridas para optimizar el flujo de aire y mejorar la refrigeración[cite: 86, 87].

##  Plan de Mantenimiento
[cite_start]Planificación para asegurar que los equipos operen correctamente durante su ciclo de vida[cite: 91].

* [cite_start]**Mantenimiento Físico:** Limpieza semestral con aire comprimido de filtros y disipadores para combatir el polvo[cite: 95].
* [cite_start]**Mantenimiento de Software:** Configuración de parches automáticos fuera del horario laboral y uso de Windows Defender[cite: 102, 103].
* [cite_start]**Seguridad de Datos:** Copia de seguridad semanal automática de todos los datos de trabajo hacia el servidor NAS[cite: 104].
